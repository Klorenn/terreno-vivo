# Territorio Vivo

Prototipo para el desafío **Innova TemucoLab 2026** (Municipalidad de Temuco): recibe prestaciones municipales con direcciones escritas en texto libre y las asigna a su unidad vecinal y macrosector, con un nivel de confianza y una bandeja de revisión que aprende de cada corrección.

- **Aplicación web:** [`territorio-vivo/`](territorio-vivo/) (Next.js). Cómo correrla, usarla y qué datos usa: [territorio-vivo/README.md](territorio-vivo/README.md).
- **Guía de uso para funcionarios:** [territorio-vivo/docs/guia-de-uso.md](territorio-vivo/docs/guia-de-uso.md) (también dentro de la app, en *Documentación*).
- **Datos y fuentes abiertas:** [territorio-vivo/docs/datos.md](territorio-vivo/docs/datos.md).
- **Diseño de interfaz:** [territorio-vivo/docs/diseno.md](territorio-vivo/docs/diseno.md) y el archivo de Figma enlazado ahí.
- **Declaración de trabajo (SOW):** [territorio-vivo-sow.md](territorio-vivo-sow.md).
